# 🎮 Tic-Tac-Toe Game in Python

A simple **Tic-Tac-Toe game** developed using Python.

This is a beginner-friendly console-based project where a human player plays against the computer.

## 📌 Project Overview

This project demonstrates basic Python programming concepts by creating a playable Tic-Tac-Toe game.

The player uses **O** and the computer uses **X**.

The computer randomly selects an available position on the board.

## 🛠️ Technologies Used

* Python
* Random module

## 🎯 Features

* Human vs Computer gameplay
* 3 × 3 Tic-Tac-Toe board
* Random computer moves
* Input validation
* Checks for winner
* Checks for draw
* Prevents selecting an occupied position

## 🎮 How to Play

The board positions are:

```text
| 1 | 2 | 3 |
| 4 | 5 | 6 |
| 7 | 8 | 9 |
```

Enter a number from **1 to 9** to select your position.

Example:

```text
Enter position (1-9): 5
```

The computer will automatically select an available position.
